# File Structure

This document lists every file in the repository with a brief description of its purpose. Paths are relative to the repository root.

```
CustomOBDDashboard/
├── .gitattributes                     # Git attributes (line-ending / diff rules)
├── .gitignore                         # Root-level ignore rules (build output, IDE files, local config)
├── build.gradle.kts                   # Top-level Gradle build script; declares plugins shared by all modules
├── settings.gradle.kts                # Gradle settings; declares repositories and includes the `:app` module
├── gradle.properties                  # Global Gradle/JVM/AndroidX configuration flags
├── gradlew / gradlew.bat              # Gradle Wrapper launch scripts (Unix / Windows)
├── gradle/
│   ├── gradle-daemon-jvm.properties   # Pins the JVM used by the Gradle daemon
│   ├── libs.versions.toml             # Centralized (version catalog) dependency and plugin versions
│   └── wrapper/
│       ├── gradle-wrapper.jar         # Gradle Wrapper executable jar
│       └── gradle-wrapper.properties  # Wrapper configuration (Gradle distribution URL/version)
├── docs/
│   ├── README.md                      # Documentation index / table of contents
│   ├── ARCHITECTURE.md                # High-level architecture and data-flow overview
│   ├── SETUP.md                       # Build, run, and development environment instructions
│   └── FILE_STRUCTURE.md              # This file: full file tree with descriptions
└── app/                                # Android Automotive OS application module
    ├── .gitignore                     # Module-specific ignore rules (build/, local files)
    ├── build.gradle.kts               # App module Gradle build script (SDK versions, dependencies)
    ├── proguard-rules.pro             # ProGuard/R8 rules for release builds (currently minimal/commented out)
    ├── release/
    │   ├── app-release.aab            # Prebuilt release Android App Bundle artifact
    │   ├── output-metadata.json       # Build output metadata generated by the Android Gradle Plugin
    │   └── baselineProfiles/
    │       ├── 0/app-release.dm       # Baseline profile dex metadata (variant 0) for startup optimization
    │       └── 1/app-release.dm       # Baseline profile dex metadata (variant 1) for startup optimization
    └── src/
        ├── main/
        │   ├── AndroidManifest.xml            # App manifest: permissions, activity, Android Auto/Automotive service declarations
        │   ├── ic_launcher-playstore.png       # Play Store listing icon
        │   ├── java/com/example/ibizacustommap/
        │   │   ├── IbizaCarService.kt          # `CarAppService` entry point for Android Auto/Automotive; creates the session
        │   │   ├── IbizaSession.kt             # `Session` implementation that launches the main car screen
        │   │   ├── MainActivity.kt             # Phone-side launcher Activity; handles runtime permission requests and shows status UI (Jetpack Compose)
        │   │   ├── MainScreen.kt               # Car-screen `Screen`/`SurfaceCallback` implementation; owns OBD polling thread, telemetry state, and the custom GT3-style dashboard renderer
        │   │   ├── ObdDecoder.kt               # Pure functions that parse raw ELM327/OBD-II hex responses into engineering values (RPM, speed, AFR, MAF, temps, etc.)
        │   │   ├── ObdManager.kt               # Bluetooth SPP connection manager; discovers, connects to, and communicates with an ELM327-compatible OBD-II adapter
        │   │   └── ui/theme/
        │   │       ├── Color.kt                # Jetpack Compose color palette constants (Material theme)
        │   │       ├── Theme.kt                 # Compose `MaterialTheme` setup (light/dark/dynamic color schemes)
        │   │       └── Type.kt                  # Compose `Typography` definitions
        │   └── res/
        │       ├── drawable/
        │       │   ├── ic_launcher_background.xml # Adaptive launcher icon background layer
        │       │   ├── ic_launcher_foreground.xml # Adaptive launcher icon foreground layer
        │       │   └── seat_logo.png               # SEAT brand logo used on the phone waiting screen
        │       ├── mipmap-anydpi-v26/
        │       │   ├── ic_launcher.xml              # Adaptive icon reference (round-capable devices)
        │       │   └── ic_launcher_round.xml         # Adaptive round icon reference
        │       ├── mipmap-{hdpi,mdpi,xhdpi,xxhdpi,xxxhdpi}/
        │       │   ├── ic_launcher.webp              # Legacy launcher icon per density bucket
        │       │   ├── ic_launcher_foreground.webp   # Legacy adaptive icon foreground per density bucket
        │       │   └── ic_launcher_round.webp         # Legacy round launcher icon per density bucket
        │       ├── values/
        │       │   ├── colors.xml                    # Named color resources
        │       │   ├── ic_launcher_background.xml    # Launcher icon background color resource
        │       │   ├── strings.xml                    # App string resources (app name)
        │       │   └── themes.xml                     # Android view-system theme definitions
        │       └── xml/
        │           ├── automotive_app_desc.xml        # Declares this app as an Android Automotive navigation app
        │           ├── backup_rules.xml                # Android auto-backup inclusion/exclusion rules
        │           └── data_extraction_rules.xml       # Android 12+ data extraction rules (backup/transfer)
        ├── androidTest/java/com/example/ibizacustommap/
        │   └── ExampleInstrumentedTest.kt      # Default instrumented test template (runs on-device)
        └── test/java/com/example/ibizacustommap/
            └── ExampleUnitTest.kt              # Default local unit test template (runs on JVM)
```
